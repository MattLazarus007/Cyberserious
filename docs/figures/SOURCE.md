# Where the figures come from

The four diagrams in this folder are the security figures from the
Deliverable 3 feedback document, the group's own work. They show the
trust boundaries, the access control picture, the lifecycle controls
and the notification workflow.

Small branding images from the same document were left out. Only the
system diagrams belong here.

The implementation corrects several details from these drawings before
building them. The corrections are listed in the specification,
sections 3.1 to 3.3, and each one is recorded in the decision log
under docs/adr. The rebuilt versions for the marker ship inside the
regulator web app as architecture.html.
