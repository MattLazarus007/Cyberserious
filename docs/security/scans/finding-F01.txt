Advisory:

- Identifiers: CVE-2026-111181, GHSA-27r3-jxmh-p828.
- CVSS: 7.5, High.
- Cause: body-parser stops listening for errors on its decompression stream.
  A request that carries a gzip Content-Encoding can therefore crash the
  process. The default configuration has inflate enabled.
- Reach: any route that accepts a request body, including the login route.
- Fixed in: 1.20.9 and 2.4.0.

Path into this tree: body-parser is not a direct dependency. Express 5.3.0
depends on it, and the lockfile resolved 2.3.0.

    cyberserious@ /Users/operator/cyberserious
    └─┬ express@5.3.0
      └── body-parser@2.3.0

Fix: an overrides entry in package.json pins the transitive package.

    "overrides": {
      "body-parser": "^2.4.0"
    }

After the install the tree resolves 2.4.0:

    └─┬ express@5.3.0
      └── body-parser@2.4.0
