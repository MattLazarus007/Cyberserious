# Phase NN task file

## Objective

One paragraph. What this phase builds and which specification
sections it answers.

## Files

Every file the phase creates or changes, with one line on each.

## Steps

Ordered steps, test first throughout. Each step names its command
and the output that counts as done. No step starts until the one
above it is green.

## Verification

The exact commands for the phase exit, copied from the plan, with
room beside each for the actual result and the date it passed.
