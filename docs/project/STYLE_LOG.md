# Style log

Every document in this repository passes three checks before it is committed:

1. punctuation: no em dash, no semicolon joining clauses
2. vocabulary: none of the filler words (delve, leverage, robust, streamline,
   comprehensive, seamless, pivotal, foster, facilitate)
3. rhythm: sentence lengths must vary. A file of equal-length sentences gets
   rewritten

The checks are deliberate. Reports written in flat, even prose read as machine
output to an examiner, and the same flatness spreads into the interface copy.
